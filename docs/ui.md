# Dashboard bar

Graph first. The state map fills the main view. Side panels for details, not
the other way around.

- Dark theme, one accent color for verified failures. Predicted paths stay grey.
- Every red path links to its trace, sandbox log, and eval file. One click each.
- Live sandbox log streams during a run. No spinners hiding progress.
- Eval files render as readable cards with pass and fail history.
- Loads in under 2 seconds on demo data. Paginate everything else.

Reference standard: Linear-level polish, Langfuse-level information density.
If a screen needs a paragraph to explain itself, the screen is wrong.
